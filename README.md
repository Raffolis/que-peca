# QuePeça

Landing page desenvolvida para apresentação do projeto **QuePeça**, uma plataforma digital criada para facilitar a busca por peças automotivas usadas, conectando consumidores e desmanches de forma rápida, prática e inteligente.

O projeto foi desenvolvido com foco em:

* UX/UI Design
* Responsividade
* Apresentação visual moderna
* Estrutura de startup acadêmica
* Experiência interativa para apresentação do escopo

---

# Tecnologias Utilizadas

* React
* Vite
* Tailwind CSS
* React Router DOM
* JavaScript
* HTML5
* CSS3

---

# Objetivo do Projeto

O QuePeça busca modernizar a forma como consumidores encontram peças automotivas usadas, reduzindo:

* Tempo de busca
* Dificuldade de localização
* Falta de padronização
* Comunicação descentralizada

A plataforma conecta usuários e desmanches em uma interface intuitiva e acessível.

---

# Pré-requisitos

Antes de executar o projeto, é necessário ter instalado:

## Node.js

Download oficial:

https://nodejs.org

Versão recomendada:

```bash
Node.js 18+
```

## Gerenciador de Pacotes NPM

O NPM já é instalado automaticamente junto com o Node.js.

Para verificar a instalação:

```bash
node -v
npm -v
```

---

# Como Executar o Projeto

## 1. Baixar ou extrair o projeto

Após obter os arquivos do projeto, abra o terminal na pasta raiz.

## 2. Instalar as dependências

Execute:

```bash
npm install
```

## 3. Iniciar o ambiente de desenvolvimento

Execute:

```bash
npm run dev
```

O terminal exibirá um endereço semelhante a:

```bash
http://localhost:5173
```

Abra esse endereço no navegador.

---

# Gerar Build de Produção

Para gerar a versão otimizada do projeto:

```bash
npm run build
```

Os arquivos compilados serão gerados na pasta:

```bash
dist/
```
